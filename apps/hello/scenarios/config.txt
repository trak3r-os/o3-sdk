# The system Config screen on HELLO: the Config button is the runtime's, so the app never sees it. FIRMWARE lists the .ptf files of a
# folder (here the fixture folder, through the simulator's fake update path), checks one in slices, asks twice (F1 each) and installs;
# DISPLAY changes the theme, INFO says what is running.
#
#   build-host/apps/hello/hello_sim --scenario apps/hello/scenarios/config.txt --firmware-dir apps/hello/scenarios/firmware --out <dir>
#
# A fixture file holds one number, the size it is listed with. A name that contains "bad" fails its check. Nothing is ever written or
# flashed.
