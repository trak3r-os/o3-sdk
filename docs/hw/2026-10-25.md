## Safety first

- **Back up the SD card** first, the whole card.
- **Install by the card, by the maintainer only** (track3r-os `docs/manual/install.md`, section 1): copy the image into `Firmware/`,
  rename the copy `PolyendTracker_0.0.1.ptf` (the reset button was seen flashing only names that start with `PolyendTracker`, at most
  24 characters), make it the **only** `.ptf` in `Firmware/`, then the hidden reset button. A unit that runs track3r-os can also take
  the file through track3r-os's own USB path (`o3console.py --put` / `--update`, the same install page, section 2); once the o3sdk
  image runs there is no USB console (milestone M2b), so the way out is the card.
- **The way back** (the same page, "Going back"): every `.ptf` out of `Firmware/`, the image you want back (track3r-os or the
  official `PolyendTracker_<version>.ptf`) alone in `Firmware/`, the hidden reset button. The bootloader is separate from the image;
  a hung o3sdk image does not remove it. Check M2-15 proves this way back from an o3sdk image.
- **The Power button does nothing in these images** (the power-off is milestone M2b): turn the unit off by removing its power.
- **Volume:** headphones off the ears and the amplifier low for the first sound (M2-9). The outputs open about a second after
  power-up with one amplifier click; anything louder is a finding.

## The status LED (the only output before the screen)

`PTC19`, active low (`platform/mk66/README.md`, "Faults and blink codes"): steady on right after power-up = the SDRAM tests running;
a 100 ms pulse every second = heartbeat, all well. A code is n flashes then a pause, repeated: 2 clock, 3 SDRAM, 4 no display chip,
5 display on the slow path, 6 (twice, then heartbeat) a crash in the previous run, 8 display stalled, 9 app failed (screen dark),
10 audio bring-up failed, 11 audio fault since boot, 12 a render over 60 % of the block, 13 a key scanner did not answer. Dark = the
image did not start.
